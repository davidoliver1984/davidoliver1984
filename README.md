The project documents how I work with AI through ADRs, implementation plans and structured reviews, capturing the reasoning behind architectural decisions as well as the finished code. Designed around deterministic ingestion, secure workspace isolation, provenance-aware retrieval, OpenTelemetry observability and AWS deployment.
